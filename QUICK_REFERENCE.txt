⚡ QUICK START COMMANDS

Terminal 1 - ML Service
  cd ml-service
  $env:PYTHONPATH = "$pwd"
  python -m uvicorn app.main:app --reload --port 8000

Terminal 2 - Backend
  cd backend
  npm install    # First time only
  npm start

Terminal 3 - Frontend
  cd frontend
  npm install    # First time only
  npm run dev

❓ TROUBLESHOOTING

Port Already in Use
  netstat -ano | findstr :[PORT]
  taskkill /PID [PID] /F

Python Module Not Found
  $env:PYTHONPATH = "C:\path\to\ml-service"

MongoDB Not Connecting
  Backend will work without it (non-critical)
  Start MongoDB separately if needed

Frontend Not Loading
  npm install
  npm run dev
  Clear browser cache
